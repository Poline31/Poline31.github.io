## Data Collection

The project is based on publicly available Cyber Threat Intelligence sources.

Information is collected from:

- security reports
- government advisories
- CERT publications
- threat intelligence research
- trusted open-source intelligence sources


## Data Model

The tracker uses a structured CTI database approach.

Each campaign is analyzed using multiple dimensions:

- timeline
- threat actor
- attack motivation
- attack type
- targeted industry
- targeted region
- targeted organizations
- consequences
- intelligence sources


## Campaign Tracking

Each identified campaign is documented with:

- campaign name
- associated threat actor
- activity period
- objectives
- targets
- techniques and tools
- available evidence


## Threat Actor Analysis

Threat actors are tracked based on:

- aliases
- type
- affiliation
- geographic focus
- operational activity


## Information Operations Analysis

The project also tracks narratives connected to cyber campaigns.

Analysis includes:

- narrative type
- language
- target audience
- relationship with campaigns
- information sources


## Data Quality

Each entry is reviewed and linked to available sources to maintain traceability and reduce unsupported assumptions.
